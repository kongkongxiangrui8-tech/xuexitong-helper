# 学习通辅助填选（Tampermonkey 用户脚本）

学习通（超星）章节学习辅助脚本：自动播放、按右侧目录的对号跳节、测验自动作答与提交，并把被字体替换混淆的题干还原成正常文字。

当前版本：**v1.3.8**

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）。
2. 打开 `xuexitong-helper.user.js` → 点右上角 **Raw**，Tampermonkey 会弹出安装页；也可以新建脚本后把内容整段粘贴进去，Ctrl+S 保存。
3. 打开超星课程学习页（`*://*.chaoxing.com/mycourse/studentstudy*`），右下角出现面板即生效。

## 使用

- 勾选「辅助填选」后点「开始」；默认开启「自动提交」，核对通过后自动提交并确认。
- 取消「自动提交」可保留人工交卷；「停止」会取消尚未执行的提交或确认。
- 跳节以右侧目录的对号（✓）为准：对号一出现就点目录里的下一小节；「暂无内容」的空小节 10 秒后自动跳过。
- 倍速支持 5x / 10x，以面板底部「实际」速度为准（平台或播放器可能不接受 10x）。
- 整门课跑完时：面板变绿、弹系统通知、标签页标题前加 ✅、响一声短提示。

## 功能要点

| 能力 | 说明 |
| --- | --- |
| 对号驱动跳节 | 只认右侧目录的完成标记，不再“识别到 PPT 就抢先点下一节” |
| 只往前走 | 记住当前位置，目录高亮回退到旧小节时忽略那次对号，不会来回打转 |
| 卡住自愈 | 跳节锁 5 秒看门狗、2 秒健康检查、45 秒停滞自动重试 |
| 视频 | 播完先等对号（最多 12 秒），等不到再点「下一节」并提示 |
| 课件 | 支持 PPT / PDF / 文档 / 正文阅读页，8 秒没对号就切到「教学视频」页签 |
| 测验 | 分组请求 `deepseek-flash`（low / 32000），全部组返回完整答案后才填选 |
| 校验 | 检查题数、真实选择状态和本地答案字段，看不到保存字段就停 |
| 提交 | 提交后核对平台返回的作答记录，结果不明或报错时停止，不自动重试 |

## 字体还原

超星用 `font-cxsecret` 子集字体做替换：屏幕显示正常，复制或读取出来却是别的字（例如「坚持」显示成「乱叁」）。

脚本的做法：

1. 读取页面的 `font-cxsecret` 子集字体，把每个可疑字用该字体渲染出来；
2. 与思源黑体 `SourceHanSansCN-Normal` 逐字比对，反推被替换的真字（首次需联网下载约 8MB 参考字体，之后走缓存）；
3. 字体或参考字形不可用时，退回让模型按上下文还原，并在日志里标出「还原」和重合度。
